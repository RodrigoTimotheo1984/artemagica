# Índice do cérebro (artemagica)

Lido no começo de todo job. Uma linha por lição ou técnica: `[etiquetas] resumo → arquivo`. Até ~60 linhas; acima disso, o professor junta as parecidas. Só entra com o "ok" do usuário.

- [processo, medida] Técnico + piso alto; a nota só vale medida certo e por pedaço → licoes.md#1
- [processo, assets] Asset aprovado é oficial; se muda o desenho, vira alvo novo e é medido por dentro também → licoes.md#2
- [olheiro] Coisas que costumam passar batido: espaço entre palavras, brilho pequeno, reflexo, sombra, névoa, halo, contorno de letra → olho.md
- [lettering, fonte, texto] Fonte instalada nunca é a do molde: largura ~2%, prova de fontes, escolha no olho → licoes.md#3
- [montagem, fundo, recorte] Fatiar o molde e reconstruir só o que fica escondido → licoes.md#4
- [processo, medida, cor] Nota só com a cor convertida para sRGB, guardada por versão → licoes.md#5
- [processo, entrega] Conferir o PSD salvo, as máscaras e as duas composições → licoes.md#6
- [texto, fonte, lettering] Letra por letra, espaço entre palavras, volume como estilo de camada → licoes.md#7
- [texto, fundo, nevoa] Chamada clara sobre fundo movimentado: nuvem de cor atrás + sombra suave → tecnicas/chamada-sobre-fundo.md
