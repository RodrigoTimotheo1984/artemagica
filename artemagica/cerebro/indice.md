# Índice do cérebro (artemagica)

Lido no começo de todo job. Uma linha por lição ou técnica: `[etiquetas] resumo → arquivo`. Até ~60 linhas; acima disso, o professor junta as parecidas. Só entra com o "ok" do usuário. Lição é experiência, não obrigação: se o seu plano for melhor, siga o plano.

- [processo, montagem] Provar cedo que o PSD funciona: mover, trocar texto, outro formato → licoes.md#1
- [processo, critério] Lembrar 80%, não copiar pixel; a régua só aponta, o olho julga → licoes.md#2
- [lettering, fonte, texto] Fonte instalada raramente é a do lettering: largura ~2%, prova de fontes, escolha no olho → licoes.md#3
- [montagem, fundo, recorte] Pixels da referência só quando o elemento se solta da cena → licoes.md#4
- [medida, cor] Se medir, converta para sRGB antes → licoes.md#5
- [processo, entrega] Conferir o PSD salvo e as máscaras, não o painel → licoes.md#6
- [texto, fonte, lettering] Letra por letra, espaço entre palavras, volume como estilo de camada → licoes.md#7
- [olheiro] Coisas que costumam passar batido: espaço entre palavras, brilho pequeno, reflexo, sombra, névoa, halo, contorno de letra → olho.md
- [texto, fundo, nevoa] Chamada clara sobre fundo movimentado: nuvem de cor atrás + sombra suave → tecnicas/chamada-sobre-fundo.md
